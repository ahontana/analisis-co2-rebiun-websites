# analisis-co2-rebiun-websites
Repositorio para el análisis de sostenibilidad y rendimiento web de las páginas de bibliotecas universitarias de REBIUN. Incluye scripts para automatizar la obtención de métricas de huella de carbono y calificaciones de rendimiento
